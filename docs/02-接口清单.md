# 接口清单

基址：`http://localhost:8080`

浏览器打开 `/`（即 `static/index.html`）可以直接点测下面全部接口，按 Tab 分为：同步对话 / SSE 流式 / 工作流 / 异步任务 / 发布与并发 / 密钥 / 系统。下表是与页面一一对应的接口定义。

| 方法 | 路径 | 参数 | 说明 |
|---|---|---|---|
| POST | `/api/chat` | `prompt`, `model`(默认 mock:echo), `userId`(默认 anonymous), `appKeyRef` | 同步对话，并记一条用量 |
| GET | `/api/chat/stream` | `prompt`, `model` | SSE 流式（事件名 text/reasoning/done） |
| POST | `/api/workflow/run` | body: `{"prompt": "..."}` | LLM + 循环 3 轮 |
| POST | `/api/workflow/validate` | body: 邻接表 `{"a":["b"],"b":["a"]}` | 返回环上的边 |
| POST | `/api/task/submit` | `payload`, `taskId`(可选) | 提交异步任务 |
| POST | `/api/publish` | `nodeId`, `delaySeconds`(可选) | 建发布记录 |
| GET | `/api/publish/{id}` | — | 查状态 |
| POST | `/api/publish/{id}/claim` | — | 抢占（SCHEDULED→PUBLISHING） |
| POST | `/api/publish/{id}/finish` | `success`, `reason` | 收尾；返回 `false` 表示记录已不在 PUBLISHING |
| POST | `/api/publish/{id}/race` | `threads`(默认 20) | 并发抢占验证，正常返回 1 |
| POST | `/api/keys` | `ownerId`, `projectId`, `provider`, `apiKey` | 写入（返回脱敏串） |
| GET | `/api/keys` | `ownerId` | 列表（只有脱敏串） |
| GET | `/api/keys/{id}` | `ownerId` | 详情；不匹配返回 4030 |
| GET | `/api/usage/queries` | `userId`(可空), `limit`(默认 20) | 最近对话流水 |
| GET | `/api/usage/cost` | `userId` | 成本明细（模型 × 天） |
| GET | `/api/usage/summary` | `userId` | 累计请求数 / token / 成本 |

### 用量与成本

- `user_query_log`：每次对话一行，记录 `source`（SYNC / STREAM）、token、成本、耗时、状态；失败的调用也会记录，但 `cost_amount = 0` 且不计入汇总。
- `cost_accounting`：按 `(user_id, model, stat_date)` 聚合，唯一键防重复行；累加走 `UPDATE ... SET x = x + ?`。
- token 是估算值（`TokenEstimator`），单价在 `app.cost.pricing` 配置，和真实厂商账单无关。

## 错误响应

| 场景 | HTTP | 响应体 |
|---|---|---|
| 路径/查询参数类型不匹配（例如把 `sk-...` 填进 `{id}` 位置） | 400 | `{"code":4000,"message":"参数 id 需要 Long 类型，实际收到: ..."}` |
| 缺少必填参数 | 400 | `{"code":4001,"message":"缺少必填参数: prompt"}` |
| 请求体不是合法 JSON | 400 | `{"code":4002,"message":"请求体不是合法 JSON"}` |
| 请求方法不支持（如用 GET 调 `POST /api/chat`） | 405 | `{"code":4005,"message":"不支持的请求方法: GET"}` |
| 静态资源或未知路径不存在（含 `/favicon.ico`） | 404 | 空 |
| 业务错误（如密钥归属不匹配） | 200 | `{"code":4030,...}`，业务码优先 |
| 未预期异常 | 200 | `{"code":500,"message":"internal error"}` |

`{id}` 这类路径变量只接受数字；非数字会在参数绑定阶段被拦下并返回 400，不会进业务逻辑。

## 异步任务的失败处理

消费失败不会直接丢弃：

1. 带 `x-retry-count` 头重新投递，最多 `app.mq.max-retries`（默认 3）次；
2. 重试耗尽后写 `failed_task` 表（`task_id` / `payload` / `reason` / `attempts`），再拒绝消息；
3. 相关指标：`mq.publish.confirm`、`mq.consume.success`、`mq.consume.duplicate`、`mq.consume.retry`、`mq.consume.failed`（`GET /actuator/metrics/{name}`）。

## 验证脚本（PowerShell）

```powershell
# 1. 乐观锁：20 线程抢一条，应返回 1
$r = Invoke-RestMethod -Method Post "http://localhost:8080/api/publish?nodeId=n1" 
$id = $r.data.id
Invoke-RestMethod -Method Post "http://localhost:8080/api/publish/$id/race?threads=20"

# 2. 循环节点：返回的 round_executed 应为 3
Invoke-RestMethod -Method Post "http://localhost:8080/api/workflow/run" -ContentType 'application/json' -Body '{"prompt":"hi"}'

# 3. 越权：应返回 code=4030
Invoke-RestMethod -Method Post "http://localhost:8080/api/keys?ownerId=u1&projectId=p1&provider=openai&apiKey=sk-abcdefgh1234"
Invoke-RestMethod "http://localhost:8080/api/keys/1?ownerId=u2"
```
